## Reporting a Vulnerability

As an AI agent skill consisting of markdown specifications and documentation, this repository does not execute compiled binaries or collect user credentials.

If you identify a security issue (such as harmful prompt injection payloads or supply-chain concerns), please open a security advisory on GitHub or contact the maintainer directly at `jigneshwadhwani692@gmail.com`.
