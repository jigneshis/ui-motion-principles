# Contributing to UI Motion Principles

Thank you for your interest in improving UI Motion Principles! We welcome recipes, improvements, and translations to help make interfaces feel more intentional across the web.

## How You Can Contribute

1. **Framework Recipes**: Add idiomatic examples for Svelte, Vue, React Native, SwiftUI, or Compose to `references/motion.md`.
2. **UX Law Case Studies**: Add real-world conflicts and solutions to `references/ux-laws.md`.
3. **Agent Integration**: Help optimize triggers and prompts in `SKILL.md` for new AI coding tools.

## Development Workflow

1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/<your-username>/ui-motion-principles.git
   cd ui-motion-principles
   ```
3. Create a feature branch:
   ```bash
   git checkout -b feature/new-recipe
   ```
4. Verify changes follow the clear, concise style:
   - Defensible logic over decorative flair.
   - Real, copy-pasteable CSS or code snippets.
   - Keep `SKILL.md` frontmatter valid YAML.
5. Commit and open a Pull Request!
